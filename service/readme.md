# Service 디렉토리 설명 
봇 프로젝트 Service 디렉토리에 대한 설명  

코드 작성 및 개발 가이드라인 설명 

## 개요
봇이 제공할 수 있는 명령어, 기능을 분야로 나누어서 기능을, 명령어를 수행합니다.  

예시) 메이플스토리 (넥슨 Open API를 통한 데이터 검색) 기능은 maplestory 디렉토리에 저장합니다.

단순 API없이 간단한 채팅을 통해 수행하는 명령, 던전앤파이터 게임 API를 활용한 기능, 날씨, 금융 등 다양한 기능을 분류합니다.

## Service 전체 코딩 구조 및 규칙  
메이플스토리 디렉토리 기준으로 설명을 기준으로, Service 디렉토리 각각 내부에는 `command.py`, `utils.py`, `consts.py`, `exceptions.py`을 기본적으로 구성하며, 특정 기능 및 캐싱을 구현하기 위해서 별도로 `resolver.py` 와 같은 파일을 추가할 수 있습니다.

각 파일은 아래와 같은 기능을 수행 해야 합니다. 모든 파일은 반드시 파이썬 작성 요령 `PEP8`을 준수할 수 있도록 코드를 작성해주세요

### const.py
명령어 수행부, API 호출 및 공용 함수를 유동적으로 수행하기 위해 지정된 전역 변수들을 설정합니다.  
해당 파일은 반드시 아래와 같은 요건을 따라야 합니다. 
- 전역변수 호출시 반드시 필요한 변수만 호출하세요 `from service.finance.consts import FinanceConsts`
- 전역변수를 호출하기 위해 import문을 작성할때, 가능하면 Asterisk(*) 사용을 자제해 주세요

### command.py
디스코드 명령어를 수행하기 위해 API 혹은 함수를 실행시키고, 사용자에게 전달할 메세지를 작성합니다. (`븜 XX`)  
해당 파일은 반드시 아래와 같은 요건을 따라야 합니다.
- 안전한 API 호출 및 임의코드 실행 방지를 위해, 오직 디스코드 관련 명령어만 실행합니다. (`ctx.send(), ctx.typing()` 등)
- 명령어 실행중 예외처리, 에러가 발생한 경우에는 반드시 `CommandFailure` 예외처리를 raise 해주세요
  -  `ctx.send()` 으로 명령어 실패를 알려 사용자가 어디서 명령어를 실패했는지 원인을 명확하게 알 수 있게 문구를 작성하세요.

### utils.py
디스코드 명령어를 수행하기 위한 API, 함수를 정의합니다.  
해당 파일은 반드시 아래와 같은 요건을 따라야 합니다.  
- API, 함수를 실행중에 발생한 예외처리, 오류들은 `exceptions.py` 파일 내에 있는 예외처리 객체를 호출해주세요
- 터미널, 컨테이너 로그에 출력할 메세지(개발자용 에러 메세지)와 사용자에게 전달할 오류 메세지를 명확히 구분해서 전달해 주세요
  - 개발자용 전달 예시: `raise CommandFailure(f'API ERROR: {response.code} {response.text}')` -> 터미널, 컨테이너 로그에 출력
  - 사용자용 전달 예시: `ctx.send(f'API에 에러가 발생해서 실패했어양! 잠시후에 시도해주세양!')` -> 사용자에게 디스코드 메세지에 에러 안내
- `븜 디버그 switch` 명령어를 통해서 운영환경에서도 에러가 발생했을때 에러가 발생한 곳을 상세하게 표시해줍니다.

### exceptions.py  
디스코드 명령어를 수행하는 동안 발생할 수 있는 예외처리, 에러상황을 정의합니다. 
해당 파일은 반드시 아래와 같은 요건을 따라야 합니다.
- `from exceptions.base import UtilsBaseException`을 통해 base 예외처리를 먼저 호출해서 예외처리 카테고리를 설정합니다.
- `utils.py` 파일에 있는 API, 함수 호출 과정에서 발생한 오류는 반드시 해당 파일에 정의된 예외처리를 불러오세요
- `commands.py` 은 반드시 base에 있는 `CommandFailure`예외처리로 명령어를 종료해야 합니다.
